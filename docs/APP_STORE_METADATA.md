# BottleShelf App Store Metadata

## Version 1.0

### Promotional Text

记录护肤、彩妆、香水和小样的开封日期、到期提醒与库存位置，帮你少浪费、少重复买。

### Description

BottleShelf 是一个本地优先的美妆库存和保质期提醒工具，适合管理护肤品、彩妆、香水、小样和旅行装。

你可以记录每件产品的购买日期、开封日期、保质期、开封后使用期和存放位置，快速查看哪些产品正在使用、哪些快到期、哪些已经空瓶。

主要功能：

- 记录护肤品、彩妆、香水、小样和旅行装
- 按分类、状态和存放位置整理库存
- 根据购买日期、开封日期和使用期计算到期状态
- 支持到期前 30 天、7 天、当天和到期后提醒
- 在“今天”页面查看优先使用的产品
- 标记使用中、未开封、已空瓶或已丢弃
- 本地保存产品记录和照片
- 不强制注册账号

BottleShelf Pro：

- 解锁无限产品记录
- 保留完整提醒和恢复购买能力
- 一次购买，永久使用

隐私说明：

BottleShelf 1.0 不使用开发者运营的服务器，不接入第三方广告或分析 SDK。产品记录和你选择的照片默认保存在本机，购买由 Apple App Store 处理。
