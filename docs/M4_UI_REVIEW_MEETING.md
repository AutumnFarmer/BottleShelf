# 瓶瓶罐罐 M4 UI 复盘会纪要

日期：2026-05-20
阶段：M4 UI 第一轮后复盘
参与角色：项目经理、产品经理、UI/UX、iOS 技术/QA

## 1. 会议结论

M4 第一轮方向正确：Today 首屏更温和，产品卡片信息更清楚，添加表单压力降低，分类占位图也比单一瓶子更有区分度。

但当前版本仍没有真正解决核心转化问题：

**女性用户是否愿意连续录入 3 件、5 件、10 件产品。**

下一轮不要继续堆功能，优先做三件事：

1. 连续录入闭环：让用户 3 分钟内录入 3 件。
2. 小屏和真机验收：确认 UI 在真实设备、大字号、长文本下稳定。
3. IAP 与提醒可信度：付费、恢复购买、本地通知必须真实可验。

## 2. 产品复盘

### 2.1 当前最大问题

1. 缺少连续录入模式
   保存产品后直接返回，没有“保存并继续添加”“再加一件”“沿用上次分类/位置”。

2. 未开封囤货的价值还没打透
   用户如果只填产品名、分类、位置，容易出现“未设置建议期”，囤货提醒价值不明显。

3. 录入后缺少即时奖励
   用户保存后没有明确反馈：“已帮你算出建议期”“下一件建议录入什么”。

4. 提醒可信度还不够
   代码已接入本地通知，但还缺真机到点验证和真实提醒设置页。

5. Paywall 转化上下文不强
   第 11 件突然拦截会显得硬，需要在第 8 件、第 10 件提前给出额度提示。

### 2.2 产品优先级

P0：

- 添加“保存并继续添加”。
- 连续录入时默认沿用上一次分类、位置、是否开封。
- 未开封产品增加快捷选项：刚买、今年买的、去年买的、记不清。
- 保存前展示建议期预览：预计某天前留意。
- 保存后给反馈：已记录 1 件，再加 2 件生成你的梳妆台状态。

P1：

- 第 8/10、10/10、第 11 件分层付费提示。
- 提醒设置页从占位改成真实权限状态、总开关、测试提醒。
- 记录第一轮内测指标：首日录入件数、连续录入完成率、通知授权率、Paywall 打开率。

暂不做：

- OCR、扫码、成分分析、AI 肤质建议。
- iCloud 同步、数据导出、小组件。
- 社区、电商导购、种草内容。
- 复杂自定义分类、空瓶统计大报表、价格 A/B。

## 3. UI/UX 复盘

### 3.1 当前主要问题

- 首屏空间仍偏松，Hero、统计卡占用过多，真正的产品卡露出较少。
- “今天状态稳定”是状态，不是行动；更适合直接显示“今天可优先用：某产品”。
- 0 值统计在新用户阶段占比过重，容易显得空。
- SF Symbols 图标比旧占位好，但仍偏系统感，不够像梳妆台物品。
- 添加页虽然减负，但仍是系统 Form，缺少录入完成后的收益反馈。
- 底部“库存”的箱子图标偏仓库感，可以后续换成更接近收纳/托盘的视觉。
- 详情页还没跟上 M4：照片主视觉、危险操作降权、空瓶反馈都需要补。

### 3.2 下一轮 UI 建议

Today：

- Hero 改成“今日推荐使用卡”，直接展示产品名、剩余天数、位置和主按钮。
- 统计从 2x2 再压缩为轻量摘要，只有临近建议期或超过建议期时才展开。
- 通知授权卡继续下移，不占首屏核心区域。
- 增加温和入口：继续添加梳妆台里的产品。

添加页：

- 做半分步式录入：照片、名称、分类、是否开封先完成，日期和高级信息可选补充。
- 快捷日期按钮要有选中态。
- 保存前展示建议期预览。
- 分类从 Picker 逐步改成图标网格，降低滚动选择成本。

库存页：

- 顶部筛选降噪，先保留状态分段：全部、临近、超期、空瓶。
- 分类筛选后续放到筛选 Sheet。
- 增加排序：建议期优先、最近添加、价格最高。

详情页：

- 顶部照片放大，让真实照片成为主视觉。
- 删除移到右上角更多菜单或底部危险区。
- “延后 7 天提醒”改成通知层 snooze，不修改真实建议期。
- 标记空瓶后弹出轻量反馈：是否回购、使用感。

App Store 视觉方向：

- 图标：奶白底、玫瑰色小柜/托盘、2-3 个简化瓶罐轮廓。
- 截图 1：你的化妆品，快到期前会提醒你。
- 截图 2：开封时间记不清，也能快速记录。
- 截图 3：按位置管理梳妆台、通勤包、旅行包。
- 截图 4：照片本地保存，不上传服务器。
- 截图 5：终身 Pro，无限记录。

## 4. 技术/QA 复盘

### 4.1 P0 风险

- StoreKit 仍缺真实验收：需要 App Store Connect IAP 或本地 StoreKit 配置。
- 已关闭：Paywall 不再使用固定价格兜底，商品加载不到时禁用购买并提供重新加载入口。
- 已关闭第一轮：Paywall 已改为滚动内容和底部固定购买区，仍需小屏和大字号截图验收。
- 缺少隐私政策 URL、App 图标、App Store 截图、IAP 审核截图、审核备注。

### 4.2 P1 风险

- 添加页在 iPhone SE 和大字号下可能过长。
- ProductRow 文本信息增加后，长品牌名、长产品名、大字号下可能截断。
- 详情页删除仍和常用操作在同一区域。
- “延后 7 天提醒”当前会修改真实建议期，应该改成提醒层 snooze。
- 通知调度失败目前缺诊断路径，真机验证前风险较高。
- 后续继续加字段前，需要考虑 SwiftData 迁移计划。

### 4.3 必测场景

- iPhone SE、6.1 英寸、6.7 英寸。
- Dynamic Type：Large、Accessibility Extra Extra Extra Large。
- 深色模式、提高对比度、粗体文字。
- 空库首次启动、添加第 1 件、连续添加到第 10 件、第 11 件触发 Paywall。
- 长产品名、英文品牌、超过 999 天、超过建议期很多天。
- 真机照片选择：HEIC、大图、换图、取消选择。
- 通知：授权、拒绝、改日期后重排、空瓶/删除后取消、锁屏到点触发。
- StoreKit：购买成功、取消、pending、恢复购买、删除重装恢复、离线读取权益、退款/revoked。
- TestFlight 升级：从已有 SwiftData、图片和通知数据升级到 M4。

## 5. 下一轮执行清单

### Sprint M4.1：连续录入闭环

目标：3 分钟内录入 3 件。

进度：基础代码已完成，待真机计时验证。

任务：

1. 已完成：`ProductEditorView` 增加保存动作选择：
   - 保存
   - 保存并继续添加
2. 已完成：连续添加时沿用上一次：
   - 分类
   - 位置
   - 是否开封
3. 已完成：快捷日期按钮增加选中态。
4. 已完成：未开封快捷日期：
   - 刚买
   - 今年买的
   - 去年买的
   - 记不清
5. 已完成：保存前展示建议期预览。
6. 已完成：保存后显示轻反馈：已记录，继续添加下一件。
7. 已完成：连续添加时仍遵守免费 10 件限制，达到上限后触发 Paywall。

验收：

- 空库用户可以连续添加 3 件，中间不需要反复重新选择位置。
- 保存前能看到建议期结果。
- 第 10 件以内不触发 Paywall，第 11 件触发 Paywall。

### Sprint M4.2：首屏与详情页

目标：打开 App 马上知道今天该做什么。

任务：

1. Today Hero 改成推荐产品卡。
2. 统计压缩为轻量摘要，有风险时再展开。
3. 详情页照片放大。
4. 删除移到底部危险区或更多菜单。
5. “延后 7 天提醒”改为“7 天后再提醒我”，不修改建议期。
6. 标记空瓶后增加回购/使用感轻反馈。

验收：

- 首屏至少露出 1 张完整产品卡。
- 无风险状态不展示大面积 0 值统计。
- 删除不再和常用操作并列。

### Sprint M4.3：上架风险关闭

目标：TestFlight 前关键风险可验。

任务：

1. 创建本地 StoreKit 配置或 App Store Connect IAP。
2. 已完成：Paywall 改为 `ScrollView + 底部固定购买区`。
3. 已完成：商品未加载时不展示固定价格，不允许误点购买。
4. 提醒设置页改成真实状态和总开关。
5. 增加发送测试提醒入口。
6. 小屏、大字号、深色模式截图验收。

验收：

- StoreKit 沙盒矩阵通过。
- 真机本地通知到点触发通过。
- iPhone SE 大字号下购买按钮和恢复购买可见。

## 6. 关键指标

内测时重点看：

1. 首次打开到添加第一件的时间。
2. 首次会话录入件数。
3. 连续录入 3 件完成率。
4. 添加页中途退出率。
5. 通知授权率。
6. 第 8 件、第 10 件提示后的继续录入率。
7. 第 11 件 Paywall 转化率。
